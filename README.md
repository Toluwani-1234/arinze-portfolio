# Arinze Akuagbazie - Portfolio

Static site: `index.html` plus the `assets/` folder. No build step.

## Deploy
- **Netlify:** drag the whole folder onto app.netlify.com/drop.
- **Vercel:** `npm i -g vercel`, then run `vercel --prod` inside this folder.
- **GitHub Pages:** push the folder to a repo, then Settings > Pages > deploy from the main branch root.

## Edit
- Contact details are in the `#contact` block at the bottom of `index.html`.
- Replace or add project photos in `assets/` and update the matching `<img src>`.
- When software projects are ready, replace the `#software` section.
